## SPANISH
Debes obtener los siguientes archivos .dll correspondientes a la versión 
de tu servidor de Terraria / TShock:

1. OTAPI.dll         -> Proporcionado por Open Terraria API.
2. TerrariaServer.dll -> El ejecutable/librería oficial del servidor de Terraria.
3. TShockAPI.dll     -> Proporcionado por el framework de servidores TShock.
4. ModFramework.dll  -> Dependencia de bajo nivel de OTAPI.
## ENGLISH
You must obtain the following .dll files corresponding to the version
of your Terraria / TShock server:

1. OTAPI.dll -> Provided by the Open Terraria API.
2. TerrariaServer.dll -> The official Terraria server executable/library.
3. TShockAPI.dll -> Provided by the TShock server framework.
4. ModFramework.dll -> A low-level dependency of OTAPI.
